# Harold - Portfolio — Full Website

## Source

https://sites.leadconnectorhq.com/preview/AmVBcIP5WHfL6SvsQzqS?notrack=true

## Included files

- `original.html`: original HTML response from the supplied public preview, including embedded styles, custom JavaScript, rendered page sections, and LeadConnector hydration data.
- `index.html`: the same full page with root-relative asset and email-protection links made absolute to their original host.
- `external-resources.json`: inventory of absolute HTTP resource and link references in the page source.

Sections include the hero and revenue pathway, brand logos, services, results media, portfolio galleries (automations, chat agents, voice agents, websites and funnels), tools, testimonials, contact form, and footer.

## Preview and limitations

Serve this folder using a static web server and open `index.html`. This is a browser-delivered source backup, not an export of the LeadConnector account or visual editor. External images, videos, fonts, runtime JavaScript, booking services, and form endpoints remain on their original hosts. They require internet access and may enforce origin restrictions. Private backend code, CRM settings, databases, and account configuration are not available from a public preview URL. No test contact form submissions were sent.

The earlier portfolio remains at the repository root. This full website backup is independent of that earlier page and of the previously published Sites/Codverter previews.
