# Harold - Portfolio

Harold's portfolio of graphics, video editing, websites and funnels, Go High Level workflows, and n8n automations.

## Files

- `index.html` — complete portfolio, all five project sections
- `styles.css` — responsive layout with full, uncropped project images
- `app.js` — keyboard-accessible image viewer and video playback coordination

Open `index.html` in a modern browser, or serve this directory with any static web server. No build step or dependencies are required.

Original project images, videos, website links, and booking link are preserved. Media is hosted on the original external providers; continued availability depends on those providers.
